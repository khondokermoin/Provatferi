# Provatferi — Developer শুরু করার আগে এটা পড়ুন

## কাজ কোথায় করবে
`cms/` (local XAMPP) ফোল্ডারে কাজ করবে। `public_html/` শুধু live সাইটের কপি — এখানে সরাসরি কাজ/এক্সপেরিমেন্ট করবে না। কাজ শেষে থিম/প্লাগইন ফোল্ডার `cms/wp-content/` থেকে `public_html/wp-content/`-এ কপি হবে।
